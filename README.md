<h1>Du-zilla</h1>

<h4>This site is based on a social network where users can post their own portfolio or view someone else's. This way, services, jobs, vacancies and CVs can be posted in a simple and practical way. In addition, the platform has an evaluation method so that whoever is viewing the CV has an idea of the quality of the service.</h4>
